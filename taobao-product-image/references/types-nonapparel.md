# 非服饰类（4 种）参数与 prompt 详解

本文件给 agent 在生成非服饰类商品图时参考，**不需要全文 Read**——SKILL.md 的类型路由表已经覆盖了 80% 的场景。只有当用户问"为什么生成出来效果不对"或想精细调 prompt 时才进来查。

## white-bg · 白底主图

**用途**：淘宝主图第 1 张，纯白底标准。

**接口**：`POST /v1/images/edits`（图生图，把商品放到新背景上）

**默认 size**：`1024x1024`

**关键参数**：
- `--image`（必填）：商品实物图
- `--product-hint`（可选）：商品类别，如 `耳机` / `咖啡机` / `玩具`，能让模型更准

**Prompt 要点**：
- 纯白 `#FFFFFF` 无缝背景
- 商品居中，占 ~70%
- 柔光、轻微底部投影（淘宝规范要求）
- 不要文字 / logo / 边框

**调优建议**：
- 商品本身背景复杂（如有文字水印）→ 效果会受影响，先用其他工具清理
- 反光 / 透明商品（玻璃、塑料壳）→ 边缘可能糊，可改用 `--quality medium`
- 异形商品（不规则形状）→ 模型可能误判主体，加 `--product-hint`

---

## scene · 场景图

**用途**：淘宝主图第 2-3 张，生活化使用场景。

**接口**：`POST /v1/images/edits`

**默认 size**：`1024x1024`

**关键参数**：
- `--image`（必填）
- `--scene`（强烈推荐）：场景描述，越具体越好
- `--product-hint`（可选）

**好场景示例**（给用户的提示）：
- 家居类：`北欧风客厅，木质茶几，暖色阳光透过窗帘`
- 数码类：`现代办公桌，金属台灯，深色木纹背景，浅景深`
- 美食类：`大理石台面，早晨柔光，旁边放一杯咖啡和书`
- 户外类：`草地野餐场景，自然光，浅景深背景`

**Prompt 要点**：
- 三分构图，商品占 30-50%
- 场景光与商品质感融合
- 浅景深，背景虚化
- 不加文字水印

**调优建议**：
- 场景描述带"风格词"效果更稳：`北欧`、`日式`、`极简`、`复古`、`工业风`
- 不要写太多场景物品，会喧宾夺主
- 商品与场景风格要匹配（不要把科技产品放田园场景）

## selling-point · 卖点图

**用途**：淘宝主图第 4-5 张，带营销文案。

**接口**：`POST /v1/images/edits`

**默认 size**：`1024x1024`

**关键参数**：
- `--image`（必填）
- `--selling-point`（必填）：逗号分隔的卖点词
- `--product-hint`（可选）

**卖点文案建议**：
- 控制在 3-5 个短词，太长文字会糊：`超大容量, 长续航, 快充`
- 用营销词：`爆款`、`新品`、`限时`、`热销`
- 避免长句子，gpt-image-1 渲染中文长句偶有错字

**Prompt 要点**：
- 商品占 60-70%（仍然是主角）
- 卖点作为版式元素叠加（badge / ribbon / 角标）
- 红橙强调色（淘宝/天猫视觉惯例）
- 现代粗体中文 sans-serif

**调优建议**：
- 文字渲染失败（出现错字/糊字）→ 缩短卖点文案，每词 4-6 字最佳
- 卖点位置不对 → gpt-image-1 自由发挥，难以精确控制，建议接受默认或改用 A+ 类型

## aplus · A+详情图

**用途**：淘宝详情页长幅图，多卖点组合。

**接口**：`POST /v1/images/generations`（**纯文生图，不需要参考图**）

**默认 size**：`1536x1024`（宽幅 3:2）

**关键参数**：
- `--selling-point`（必填）
- `--brand`（可选）：品牌名
- `--product-hint`（推荐）：商品类别很重要，因为是纯文生图

**Prompt 要点**：
- 左/中是产品 hero
- 右侧 2-3 个卖点卡片（编号 1/2/3）
- 统一 3-4 色调色板
- 现代粗体中文

**调优建议**：
- `--product-hint` **必给**，否则模型不知道生成什么商品
- 卖点不要超过 3 个，否则排版乱
- 宽幅图文字渲染挑战大，建议每词 4-8 字

## 共享调优技巧

### gpt-image-1-mini vs gpt-image-1
- `gpt-image-1-mini`：$0.005/张 (low)，便宜默认
- `gpt-image-1`：$0.011-$0.25/张 (low-high)，质量高，复杂场景建议

切换：`--model gpt-image-1`

### quality 等级
- `low`：默认，便宜快速，适合迭代试稿
- `medium`：折中
- `high`：精修，最终稿推荐

切换：`--quality high`

### size 改写
- 淘宝主图标准 1:1 → `1024x1024`
- 详情页宽幅 → `1536x1024`
- 模特图竖幅 → `1024x1536`（gpt-image-1 支持任意纵横比）
