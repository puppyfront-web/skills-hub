# doc-creation-workflow

结构化文档创作的通用工作流技能。12 个写作技巧 + 8 个按需安装的扩展技能，覆盖从选题到发布的全流程。

## 这是什么

一套经过实战验证的文档创作方法论。不是内容模板，是**技巧**——写技术教程、培训课件、产品文档、科普文章都能用。

## 核心结构

```
规划（技巧 1-2）→ 写作（技巧 3-6）→ 排版（技巧 7-9）→ 交付（技巧 10-12）
```

12 个技巧分 4 个阶段，按创作顺序排列，按需取用。

## 扩展技能（按需自动安装）

工作流内置了 8 个扩展技能的安装路径和触发逻辑。AI 执行时会根据文档类型自动判断需要哪些，静默安装并调用：

| 技能 | 阶段 | 能力 |
|------|------|------|
| copywriting | 选题 | 标题钩子、转化结构 |
| edit-article | 润色 | 结构优化、逻辑审查 |
| copy-editing | 深度润色 | 七步法逐段精修 |
| frontend-design | 美化 | 排版、配色、视觉层次 |
| svg-icon-maker | 配图 | SVG 图标生成 |
| html-svg-diagrams | 配图 | SVG 流程图/架构图 |
| seo-audit | 发布 | SEO 检查 |
| ai-seo | 发布 | AI 搜索引擎优化 |

## 使用方式

安装后，对 AI 说"帮我写一篇 XX 文档"或"美化这篇文档的排版"，AI 会自动加载这个工作流并按阶段执行。

## 依赖

- AI Agent（Claude Code / Cursor / Cline / OpenClaw 等支持 skills 的工具）
- `npx` （用于安装扩展技能，Node.js 自带）
- 扩展技能按需安装，不提前装也行
