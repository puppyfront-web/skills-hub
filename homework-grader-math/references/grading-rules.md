# 批改规则

> 本文档定义小学数学作业的批改判定规则。`scripts/compare.py` 是规则的可执行实现，本文档是规则来源与补充说明。

## 1. 答案等价归一

小学数学里，同一个答案可能有多种等价写法，批改时必须容错：

| 等价形式 | 举例 | 处理 |
|----------|------|------|
| 分数 ↔ 小数 | `1/2` = `0.5` | 转 Fraction/float 比数值 |
| 小数尾零 | `3.0` = `3` | 数值比较 |
| 带分数 | `2 1/3` = `7/3` | 解析成 Fraction |
| 中文数字 ↔ 阿拉伯 | `一百` = `100` | 中文转阿拉伯 |
| 单位有无 | `8米` = `8` | 剥离单位后比数值 |
| 全角↔半角 | `×` = `*`，`÷` = `/` | 统一符号 |
| 选项大小写 | `b` = `B` | 统一大写 |
| 判断题等价 | `对`=`√`=`T`=`正确` | 等价集合判断 |

## 2. 题型判定规则

| 题型 | 代码 | 识别特征 |
|------|------|----------|
| 计算题 | `calculation` | 纯算式，如 `25 × 4 =` |
| 填空题 | `fill_blank` | 有括号或横线待填，如 `3 × ( ) = 12` |
| 选择题 | `choice` | 有 ABCD 选项 |
| 判断题 | `judge` | 要求判断对错 |
| 应用题 | `application` | 有文字描述的实际问题 |

## 3. 错因分类

| 类型 | 代码 | 判定依据 |
|------|------|----------|
| 粗心错 | `careless` | 方法思路对，抄错数/看错符号 |
| 概念错 | `conceptual` | 方法或思路错，不理解知识点 |
| 计算错 | `calculation` | 方法对，运算过程错（进位错、口诀错） |
| 未作答 | `empty` | 学生没写答案 |

规则推断优先级（`explain.classify_error_by_rule`）：
1. 未作答 → `empty`
2. 位数相同、数字接近（差 1-2 位）→ `calculation`
3. 位数差异大（≥2 位）→ `conceptual`
4. 答案符号相反（+看成-）→ `careless`
5. 以上都不满足 → `unknown`，交 LLM 判断

## 4. 置信度与复核机制

| 来源 | confidence | need_review | 含义 |
|------|-----------|-------------|------|
| 题库命中 | 1.0 | False | 几乎无误，直接判定 |
| AI 解题 ≥0.85 | AI 自评 | False | 自动判定 |
| AI 解题 <0.85 | AI 自评 | True | 标记"建议老师复核" |
| 判定方法 unknown | — | True | 答案形式不匹配，复核 |

识别置信度（OCR 层）< medium 的题目，也会高亮提示老师校对。

## 5. 不批改的情况

- **图形/几何题**：需识别图形，V1 不支持，提示老师手动录入题面
- **未作答**：判错，error_type = empty，点评鼓励动笔
- **标准答案缺失**：AI 解题失败时，标记 need_review，不强行判错

## 6. 题库匹配阈值

- 题面归一化（去空格、统一符号）后做相似度匹配
- 阈值 **0.9**：相似度 ≥ 0.9 视为命中
- 用 `difflib.SequenceMatcher` 计算相似度
- 未命中走 AI 解题，教师确认后可回写题库
