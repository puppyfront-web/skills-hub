# Template Schema

## Storage Location

`~/.openclaw/skill-state/invoice-ocr-templates/`

```
invoice-ocr-templates/
├── index.json              # supplier lookup index
├── wangtai-textile.json    # one file per supplier
├── yubo-fabric.json
└── ...
```

## Index File (`index.json`)

```json
{
  "version": 1,
  "templates": {
    "<supplier_id>": {
      "supplier_name": "旺泰纺织",
      "aliases": ["旺泰", "旺泰纺织"],
      "file": "<supplier_id>.json"
    }
  },
  "updated_at": "2026-04-18T14:30:00"
}
```

## Template File (`<supplier_id>.json`)

```json
{

  "supplier_name": "旺泰纺织",
  "supplier_aliases": ["旺泰", "旺泰纺织"],
  "created_at": "2026-04-18T14:30:00",
  "updated_at": "2026-04-18T14:30:00",
  "source_count": 3,
  "format_description": "Standard printed delivery note, columnar layout: 货名/色号/数量/单位/单价/金额. No handwritten fields observed.",
  "field_layout": {
    "note_number_pattern": "XS\\d{8,}",
    "items_table_type": "columnar",
    "item_row_fields": {
      "material_type": { "present": true, "observed_rate": "2/2" },

```

## Field Descriptions

| Field | Purpose |
|-------|---------|
| `supplier_name` | Full supplier name from invoice |
| `supplier_aliases` | Searchable aliases for matching (auto-generated from name) |
| `source_count` | Number of invoices used to build/refine template |
| `format_description` | Free-text layout description, injected into extraction prompt |
| `field_layout` | Structured description of which fields exist and their positions |
| `item_row_fields` | Per-field presence tracking with observed_rate (e.g. "3/4" = 3 of 4 items had this field) |
| `extraction_hints` | Supplier-specific quirks: handwritten fields, common material types, default unit |
| `field_mapping_corrections` | User corrections stored for future reference（后续使用中**每次**口头纠偏、确认时若有可复用规则，都应追加至此，**不要**只改当次表而不记） |
| `sample_extraction` | Reference extraction for validation |

## Template ID Generation

Supplier ID is generated by replacing non-alphanumeric chars with `-`:
- `旺泰纺织` → `旺泰纺织` (CJK chars preserved)
- `汇丰水洗、砂洗厂` → `汇丰水洗-砂洗厂`
- `宣城向前洗涤有限责任公司` → `宣城向前洗涤有限责任公司`
